INORA — Multi-Channel EEG-Based Control

TIMELINE Dec 2025 – Jan 2026
TECH AD620, TL072, ADS1115, ESP32, Python, NumPy
  • Built a low-cost 3-channel EEG acquisition system with wireless streaming at 83 Hz/channel, and developed a Python pipeline for EEG acquisition, filtering, and DRL-based noise reduction, validated on 20 volunteers.
  • Demonstrated EEG-based Pong control with valid 15–80 µV signals using hardware costing INR 3,146.
Live Demo

HARDWARE & SIGNAL PROCESSING HIGHLIGHTS

  • Custom hardware stack incorporating AD620 instrumentation amplifier, TL072 active filtering stage, ADS1115 16-bit ADC, and ESP32 wireless telemetry.
  • Python acquisition pipeline featuring real-time FFT feature extraction, bandpass filtering, and Deep Reinforcement Learning (DRL) noise reduction.
  • Clinical & performance validation on 20 test subjects, maintaining reliable signal fidelity (15–80 µV) for real-time Pong gameplay control.

BrainScore — EEG-Based Depression Detection

TIMELINE Mar 2025 – Nov 2025
TECH Python, Pandas, Scikit-learn, LightGBM, SHAP, Google Colab
  • Processed EEG recordings from 58 subjects using 20-channel signals and extracted 18 statistical, frequency, and entropy-based biomarkers; built and evaluated 6 machine learning models.
  • Achieved 95.28% classification accuracy using LightGBM, with SHAP analysis to interpret feature importance and improve model explainability for automated depression detection.
Project Cover Image

MODEL ARCHITECTURE & EXPLAINABILITY

  • Benchmarked 6 Machine Learning algorithms (including LightGBM, Random Forest, XGBoost, and SVM) on 58 subject datasets.
  • Leveraged SHAP (SHapley Additive exPlanations) for quantitative feature attribution, establishing clinical interpretability for automated depression diagnostics.
